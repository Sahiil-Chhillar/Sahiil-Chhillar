<h3>
  <img src="https://img.shields.io/badge/01-22d3ee?style=flat-square&label=&labelColor=22d3ee" alt=""/>
  &nbsp;Attendyy &nbsp;<sub><i>attendance verification platform</i></sub>
</h3>

<table>
<tr><td width="62%" valign="top">

A full-stack **MERN attendance system** designed to reduce proxy attendance using
dynamic, time-bound QR codes combined with **Haversine-based geolocation verification**.

Authentication uses **JWT** with **role-based access control** across Student, Teacher
and Admin roles. Signup includes **OTP verification**, while **Cloudinary** handles
avatar uploads.

The platform combines QR-based attendance, location verification and role-specific
workflows into one attendance management system.

</td><td width="38%" valign="top">

**Stop proxy attendance**
### `QR + location`
time-bound QR codes · Haversine verification

`3` user roles
<br/>JWT authentication
<br/>OTP-verified signup
<br/>Cloudinary avatar uploads

</td></tr>
</table>
